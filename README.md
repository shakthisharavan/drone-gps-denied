# ISRO-SDK
Autonomous drone navigation using ROS, sensors and computer vision 
## Objective
Autonomous navigation without GPS using ROS2, LiDAR, IMU, and Vision.

## Tech Stack
- ROS2
- PX4 / Ardupilot
- LiDAR
- Jetson
- OpenCV

## Features
- SLAM Mapping
- Obstacle Avoidance
- Path Planning
